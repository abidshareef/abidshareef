# Featured Systems

<details>
<summary><strong>NAV-AION — Intelligent Dead Reckoning for GNSS-Denied Navigation</strong></summary>

### Problem

Navigation systems can degrade when GNSS becomes unavailable inside tunnels, underground environments, parking structures and difficult urban corridors.

### System

NAV-AION combines **GNSS + IMU + inertial navigation + machine learning + map constraints + uncertainty-aware fusion** to maintain navigation continuity during GNSS outages.

### Architecture

~~~text
GNSS ───────────────┐
                    │
IMU ──► Preprocess ──┼──► Error-State Filter ──► ML Confidence ──► Fusion
                    │                                      │
Map / Road Network ─┴──────────────────────────────────────┤
                                                           ▼
                                              Position + Velocity
                                                           │
                                                           ▼
                                                Map-Matched Route
~~~

| Area | Implementation Direction |
|---|---|
| Sensor Fusion | GNSS + IMU |
| Estimation | ESKF / inertial state estimation |
| ML | Temporal Convolutional Network |
| Constraints | Non-holonomic + map constraints |
| Robustness | GNSS outage detection and recovery |
| Edge | Lightweight inference for low-end devices |
| Product | Mobile navigation prototype with OpenStreetMap |

**Repository:** [SIH26168](https://github.com/abidshareef/SIH26168)

</details>
